# Founder Accountability Coach
### A folder-based AI coach for early-stage founders — day #1 to day #90

> 🔴 Live version: [daynumber.io](https://daynumber.io) — currently on day #305

## What this is

A Claude project folder that turns Claude into a founder accountability coach. Not a startup knowledge base. Not a motivational bot. A coach that pushes back, tracks patterns, holds commitments, and asks the question you've been avoiding.

Built for founders in the hardest window: the 90 days before traction, before proof, before anyone is watching.

## How to use it

1. Create a new Claude project at claude.ai
2. Upload all files in this folder to the project knowledge
3. Tell the coach your day # and what you're building
4. Log what happened today — honestly
5. Let it coach you

## Folder structure

- identity.md — who the coach is and how it thinks
- rules.md — how it coaches (10 rules)
- examples.md — coach vs. knowledge base, side by side
- reference/day-number-framework.md — the day # system, windows, signals
- reference/coaching-drills.md — techniques for specific stuck patterns

## The live version

This folder is the distilled methodology behind dayNumber_ — a proof-of-work platform where founders log their building journey publicly every day and the AI coaches them in real time.
